# IntelliJ Typst plugin, powered by Tinymist

This plugin tries to bring the official Tinymist VS Code plugin experience to IntelliJ platform.

## typm

[typm](https://github.com/NanamiNakano/typm) is an experimental package manager for typst.
I wrote it to address poor supports of local packages and unpublished packages.

This plugin has integration with typm and should work seamlessly if you used it.
